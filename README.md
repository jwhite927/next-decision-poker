# Decision Poker

A multiplayer decision-making app. One person poses a question, shares a link, and everyone votes together.

## How it works

1. **Create a decision** — type your question or topic into the text field on the home page.
2. **Share the link** — you get a unique URL to share with others (e.g. `/decision/abc123`).
3. **Add opinions** — participants join via the link and submit their input privately.
4. **Reveal & discuss** — all opinions are revealed at once; another round of input can then be gathered to refine the group's thinking.

## Tech stack

- [Next.js 16](https://nextjs.org) (App Router)
- [React 19](https://react.dev)
- [Tailwind CSS 4](https://tailwindcss.com)
- [Supabase](https://supabase.com) (Postgres)
- TypeScript
